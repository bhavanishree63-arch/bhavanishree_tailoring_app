# BHAVANISHREE TAILORING SHOP — Setup Guide

இந்த ஆப் இப்போது **Supabase** (இலவச கிளவுட் தரவுத்தளம்) பயன்படுத்துகிறது — அதனால்
உங்கள் தொலைபேசி, டேப்லெட், கணினி எதிலிருந்தும் ஒரே வாடிக்கையாளர் தரவை
பார்க்க/மாற்ற முடியும். செய்ய வேண்டியது 3 படிகள் மட்டும்:

## படி 1 — Supabase Project உருவாக்கு

1. https://supabase.com க்குச் சென்று இலவசமாக ஒரு கணக்கு உருவாக்கவும்.
2. "New Project" ஐ அழுத்தி ஒரு project உருவாக்கவும் (பெயர்: `bhavanishree` என வையுங்கள்).
3. Project தயாராகும் வரை 1-2 நிமிடம் காத்திருக்கவும்.

## படி 2 — அட்டவணைகளை உருவாக்கு

1. இடது பக்க மெனுவில் **SQL Editor** ஐ திறக்கவும்.
2. இந்த கோப்பில் உள்ள முழு SQL-ஐயும் நகலெடுத்து ஒட்டவும்: `supabase_schema.sql`
3. **Run** பட்டனை அழுத்தவும். "Success" என்று காண்பித்தால் முடிந்தது.

இது 3 அட்டவணைகளை உருவாக்கும்: `customers`, `measurements`, `patterns`.

## படி 3 — ஆப்-ஐ உங்கள் Project உடன் இணை

1. Supabase Dashboard இல் **Project Settings → API** க்குச் செல்லவும்.
2. **Project URL** மற்றும் **anon public key** ஐ காப்பி செய்யவும்.
3. இந்த ஆப்-ன் `js/db.js` கோப்பை திறந்து, மேலே உள்ள இந்த 2 வரிகளை மாற்றவும்:

```js
const SUPABASE_URL = 'https://YOUR-PROJECT-REF.supabase.co';
const SUPABASE_ANON_KEY = 'YOUR-SUPABASE-ANON-KEY';
```

உங்கள் சொந்த URL மற்றும் key-ஐ இங்கே ஒட்டவும், கோப்பை சேமிக்கவும். முடிந்தது —
ஆப் இப்போது Supabase-உடன் இணைந்துவிட்டது.

⚠️ இந்த 2 மதிப்புகளையும் யாருக்கும் தெரியாமல் வைத்திருங்கள் (இதை பொது
GitHub repo-வில் பதிவேற்றாதீர்கள்) — ஏனெனில் இவை உங்கள் தரவை யார்
வேண்டுமானாலும் படிக்க/மாற்ற அனுமதிக்கின்றன (login அமைப்பு இல்லாததால்).

## இணையத்தில் (hosting) வெளியிட

இந்த `project` கோப்புறை முழுவதையும் எந்த static hosting-லும் (Netlify, Vercel,
GitHub Pages, cPanel) பதிவேற்றினால் போதும் — சர்வர்-சார்ந்த கோட் எதுவும் இல்லை.

## 100+ பழைய வாடிக்கையாளர்களை Excel மூலம் ஒரே முறையில் சேர்க்க

1. ஆப்-ஐ திறந்து **⚙️ அமைப்புகள் → Excel / CSV இறக்குமதி** க்குச் செல்லவும்.
2. **"காலி Excel வார்ப்புருவைப் பதிவிறக்கு"** பட்டனை அழுத்தி டெம்ப்ளேட்டைப் பெறவும்.
3. அந்த Excel கோப்பில் ஒரு வரிசைக்கு ஒரு வாடிக்கையாளர் என நிரப்பவும்
   (பெயர், தொலைபேசி, மாடல் — Blouse/Chudithar, தேவையான அளவுகள்).
4. அதே திரையில் அந்த கோப்பை பதிவேற்றி, சரிபார்த்த பிறகு **"இறக்குமதி செய்"**
   பட்டனை அழுத்தவும். அனைவரும் உடனே **வாடிக்கையாளர்கள்** பக்கத்தில் தோன்றுவார்கள்
   — ஒவ்வொருவரையும் தனித்தனியாக தட்டச்சு செய்யத் தேவையில்லை.
5. `.csv` கோப்பாகவும் பதிவேற்றலாம் — Excel-இல் "Save As → CSV" செய்தால் போதும்.

## சுடிதார் அளவுகள் (புதுப்பிக்கப்பட்டது)

வாடிக்கையாளர் மாடலாக "சுடிதார்" தேர்ந்தெடுக்கும்போது இப்போது இந்த 13
அளவுகள் கேட்கப்படும்:

1. கை உயரம்
2. கை அக்குள்
3. முழு உயரம்
4. கழுத்து
5. சோல்டர்
6. பின் கழுத்து
7. முன் கழுத்து
8. பாடி மார்பு.சு
9. ஒப்பன் உயரம்
10. பட்டி
11. கீழ் அகலம்
12. Box Line Height
13. கைச்சுற்றளவு

(Box Line Height + கைச்சுற்றளவு அளவுகள் இருந்தால், வாடிக்கையாளர் பக்கத்தில்
ஆர்ம்ஹோல் வரைபடமும் தானாகவே தோன்றும் — பிளவுஸ் போலவே.)
